Privacy Policy

1. Local-First & Complete Privacy Assurance
This application is built with a local-first architecture. It does not require or perform any internet access whatsoever.

2. Collection of Personal Information
This application does not collect, store, share, or transmit any personal information or user data.

3. File and System Access
Although this application requests the runFullTrust capability to function as a desktop application, all file operations and configuration managements are processed locally on the user's device. No data is sent to external servers.

4. Contact
If you have any questions, please open a GitHub issue.
