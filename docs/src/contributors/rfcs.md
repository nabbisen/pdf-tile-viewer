# RFC Index

The single, authoritative RFC index is [`rfcs/README.md`](https://github.com/nabbisen/pdf-tile-viewer/blob/main/rfcs/README.md)
in the repository. It lists every RFC by state: proposed, accepted (implementation
may start), implemented, and archived (withdrawn or superseded), together with the
developer handoffs.

RFCs follow the lifecycle policy in
[`rfcs/done/000-rfc-lifecycle-policy.md`](https://github.com/nabbisen/pdf-tile-viewer/blob/main/rfcs/done/000-rfc-lifecycle-policy.md):
the folder an RFC lives in is its state, and implemented RFCs are never deleted.
