# Project Goals and Philosophy

PDF Tile Viewer's core values:

1. **Local-first** — No network, no account, no telemetry.
2. **Privacy safe by default** — Full paths, recent history, and diagnostics
   are all opt-in.
3. **Rust-first** — All product logic lives in Rust. No TypeScript, no JS
   stores, no frontend build step.
4. **Single PDF engine** — PDFium for open, render, and search. No PDF.js.
5. **Design before coding** — Every significant change starts with an RFC.
   See `rfcs/README.md`.
