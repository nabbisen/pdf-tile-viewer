# Supported Platforms

| Platform | Architecture | Status |
|----------|-------------|--------|
| Linux (x86-64) | `x86_64-unknown-linux-gnu` | ✅ Primary development target |
| macOS (Apple Silicon) | `aarch64-apple-darwin` | Beta release artifact target |
| Windows (x86-64) | `x86_64-pc-windows-msvc` | Beta release artifact target |

Older macOS (Intel) and 32-bit platforms are not planned.
