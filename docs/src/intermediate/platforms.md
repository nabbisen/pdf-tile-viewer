# Supported Platforms

| Platform | Architecture | Status |
|----------|-------------|--------|
| Linux (x86-64) | `x86_64-unknown-linux-gnu` | ✅ Primary development target |
| macOS (Apple Silicon) | `aarch64-apple-darwin` | Release artifact target |
| macOS (Intel) | `x86_64-apple-darwin` | Release artifact target (built and smoke-tested in the release matrix) |
| Windows (x86-64) | `x86_64-pc-windows-msvc` | Release artifact target (an MSIX package is also built for Microsoft Store submission) |

32-bit platforms are not planned.
